the killer feature

A secure pipe between any two machines

Drop bandrop pipe into any Unix pipeline. No ssh, no open ports to manage, no server — just a short code and an encrypted stream.

  • Bidirectional, so it composes both ways
  • Pairs with SPAKE2, sealed with AES-256-GCM
  • Moves databases, tarballs, disk images — anything a pipe carries
secure pipe
# host A
$ pg_dump db | bandrop pipe --to hostB

# host B
$ bandrop pipe --listen > db.sql

# or move a whole tree, no temp files
$ tar c ./project | bandrop pipe --to hostB
encrypted end-to-end · direct, always

Security you can reason about

A short code is enough because pairing is a real PAKE — an attacker gets one online guess per connection, never an offline brute force.

Pairing
SPAKE2 · RFC 9382, P-256
In transit
AES-256-GCM · per-frame nonce
Integrity
SHA-256 · every file
Provenance
Ed25519 · signed receipts

Bandrop has a clear threat model — a trusted local network — and no relay or cloud component anywhere. serve is the one deliberate exception: plain HTTP so any browser works. It's a compact, tested tool, not an audited transport for hostile networks.

installs in seconds

Get Bandrop

One line builds from source and pulls its own dependencies on Linux and macOS.

install
# one line
$ curl -fsSL https://raw.githubusercontent.com/IlieBanda/bandrop/main/install.sh | sh

# or Homebrew
$ brew install --HEAD IlieBanda/bandrop/bandrop

# or from source
$ cmake -S . -B build && cmake --build build
